# Coffre-fort électronique

## Exécution

### 1. Raspberry Pi

Dans le terminal :

```bash
cd ~/tp3
source .venv/bin/activate
python app.py
```

Le serveur Flask démarre sur le port 5000 et la communication Bluetooth avec l'ESP32 est lancée.

Interface web :
`http://ADRESSE_IP_DU_RASPBERRY:5000`

### 2. ESP32

**Fichier à téléverser : `controleur_coffre.ino`**

3. Cliquer sur **Téléverser (Upload)**.
